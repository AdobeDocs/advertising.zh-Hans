# Advertising DSP中可用的第三方数据提供程序

在版面设置和保存的受众设置中，每个区段的使用费均显示在区段名称旁边。

* [!DNL digitalAudience]

* [!DNL LiveRamp]
* [!DNL Lotame]

* [!DNL Tapfwd]
* [!DNL TransUnion]
